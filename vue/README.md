# Melos Vue 前端

Melos 的 Web 前端，基于 **Vue 3 + Vite + TypeScript**。
后端（会话网关 + KuGouMusicApi）与 `/api` 同源代理保持不变。

## 技术栈

- Vue 3 + `<script setup>` + TypeScript
- Vite + `vite-plugin-pwa`
- Pinia（登录 / 播放器状态）
- Vue Router
- 原生 HTML5 Audio
- 纯白极简 UI：白底、浅灰层次、细边框、黑白按钮；无渐变 / 玻璃拟态 / 装饰光效

更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 已实现

- 扫码登录（酷狗概念版 App）
- 首页推荐（6 组推荐卡片 + 推荐歌单），右上角头像进入「我的音乐」
- 搜索歌曲、歌单、播放全部；实时搜索建议与真实热搜词
- 歌手页、专辑页；播放页的歌手 / 专辑可点击跳转，合唱歌曲的每位歌手均可点击
- 我的歌单、歌单详情
- 播放队列、上一首/下一首、进度拖动、音量、循环模式
- 音质选择（128K / 320K / FLAC），切换时保持播放位置
- 设置页：音质、音量、循环模式、歌词翻译 / 音译 / 自动滚动 / 字号、搜索建议、减少动画、账号与队列管理
- 每日 VIP：听歌奖励 + 广告奖励自动领取，显示今日进度与按本地时区换算的到期时间
- iPhone / iPad PWA 自动连播优化：预取后续 5 首并在歌曲结束后无缝切换
- 媒体会话（锁屏 / 系统媒体控制）与播放状态持久化
- 歌词（KRC / LRC 行级同步，翻译 / 音译；LRC 同行翻译合并兜底），会话内缓存避免重复加载
  - 桌面：封面左侧，歌词固定右侧
  - 手机：向右滑进入歌词页，向左滑返回封面；也可点右上角歌词图标或「查看歌词」
- 发现 / 搜索 / 歌单页 KeepAlive 缓存，进入播放页再返回不重新加载
- 评论（热门 / 最新、楼层回复、配图），内置图片查看器（缩放 / 切换）
- PWA 安装、离线壳、响应式布局：
  - 桌面：左侧栏 + 内容区 + 底部播放条
  - 手机：底部导航 + 迷你播放条 + 全屏播放页

## 开发

```bash
cd vue
npm install
npm run dev
```

开发服务器会把 `/api` 代理到 `http://127.0.0.1:3005`（容器内的会话网关）。
也可以直接使用 Docker 版本：

```bash
docker compose -f docker-compose.web.yml up -d --build
```

## 构建

```bash
# 在仓库根目录执行
./docker/build-vue.sh
# 或
cd vue && npm run build
```

产物输出到 `prebuilt/vue/`，`Dockerfile.web.vue` 会直接复制到 Nginx。
