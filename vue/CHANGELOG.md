# Melos Vue 更新日志

## 0.5.1 — 2026-11-16

- 播放页移除音质选择，音质仍可在设置页调整
- 播放控制区贴底排布，进度条与播放控件始终靠近屏幕底部
- 短屏幕上自动缩小封面，避免控制区被挤出视口
- 音量滑杆并入进度行，播放控件行保持在最下方

## 0.5.0 — 2026-11-16

- 播放页新增收藏：左侧心形按钮收藏 / 取消收藏到酷狗「我喜欢」
- 播放控制区改为「收藏 — 播放控件 — 循环模式」三栏布局，音质与音量保留在下方
- 收藏状态写入本地缓存（5 分钟内直接复用），网络较慢时先显示缓存状态并在后台刷新
- 收藏列表与增删接口增加超时和自动重试，缓解上游偶发 TLS 中断

## 0.4.5 — 2026-11-16

- 移除播放页中与右上角歌词按钮重复的「查看歌词」入口
- 歌词页继续通过右上角图标、右滑手势和左侧标签打开

## 0.4.4 — 2026-11-16

- 连播预取窗口从后续 5 首提高到 10 首
- 新增下一首音频预加载：提前缓冲下一首音频，切歌更快
- 在省流量模式或 2G 网络下自动跳过音频预加载
- 音频预加载元素保持静音、隐藏且不参与播放

## 0.4.3 — 2026-11-16

- iPhone PWA 连播增强：从只预取下一首扩展为预取后续 5 首，并在每次切歌时立即续补预取窗口
- 修复播放到第三首时没有预取地址、在 iOS 后台/锁屏状态下卡住的问题
- 预取窗口会在队列、音质或循环模式变化时自动清理，避免使用过期地址

## 0.4.2 — 2026-11-16

- 播放页歌词加入会话缓存，同一首歌再次进入不重新请求
- 合唱歌曲支持每个歌手单独点击进入歌手页
- 设置页把账号区块移到最前
- VIP 到期时间显示到分钟，按本地时区显示，非中国时区补充北京时间
- 修复歌手名重复显示（如「Daoko / 米津玄師 / Daoko、米津玄師」）

## 0.4.1 — 2026-11-16

- 修复 iPhone Web PWA 播放结束后不自动切歌：提前预取下一首播放地址，并在 `ended` 事件内同步启动，避免 iOS 阻止异步自动播放
- 增加 `ended` 事件丢失兜底与可见性恢复检查，单曲循环 / 单曲队列直接重播当前音频

## 0.4.0 — 2026-11-16

- 设置页新增「每日 VIP」：领取听歌奖励，并自动间隔约 30 秒领取剩余广告奖励
- 显示今日领取进度、每次奖励时长、今日剩余可领时长与 VIP 到期时间
- 支持中途停止、断点状态保存与继续领取

## 0.3.0 — 2026-11-16

- 新增设置页：默认音质、音量、循环模式
- 歌词设置：翻译 / 音译开关、自动滚动、歌词字号
- 搜索设置：搜索建议开关、清除最近搜索
- 外观与性能：减少动画
- 账号：查看登录状态、退出登录
- 数据：清空播放队列、恢复默认设置
- 侧栏与底部导航新增设置入口

## 0.2.0 — 2026-11-16

- 播放页新增音质选择：128K / 320K / FLAC，切换时保持当前播放位置
- 评论图片改用内置查看器，支持放大、缩小、左右切换与滑动
- 搜索页新增「歌单」分类，可搜索酷狗歌单
- 新增歌手页与专辑页；播放页的歌手、专辑名称可点击跳转
- 移除 Flutter / Linux 桌面 / VNC 版本，仓库只维护 Vue Web PWA
- 更新 README、部署文档与预编译产物

## 0.1.2 — 2026-11-16

- 移除逐字歌词与播放页 30fps 进度刷新；歌词回到行级高亮，保留 KRC / LRC 翻译与音译

## 0.1.1 — 2026-11-15

- 移动端播放页重新组织操作区：移除底部固定的「播放 / 歌词」分页点，改为右上角歌词图标 + 封面下方「查看歌词」，不再与播放控件和安全区重叠；向右滑进入歌词，向左滑返回封面
- 歌词升级为 KRC 优先：逐字高亮、`[language]` 翻译与音译、LRC 同行翻译兜底；打开播放页时以约 30fps 刷新进度
- 发现 / 搜索 / 歌单页使用 KeepAlive 缓存，进入播放页再返回不会重新请求，滚动位置自动恢复
- 搜索页接入 `/search/hot` 与 `/search/suggest`：实时搜索建议、真实热搜词
- 发现页右上角改为头像 + 在线绿点，点击进入「我的音乐」；移除「已登录」胶囊

## 0.1.0 — 2026-11-15

- 从 Flutter Web 重构为 Vue 3 + Vite + TypeScript + Pinia
- 纯白极简 UI：白色背景、细边框、黑白按钮；移除渐变与玻璃拟态
- 使用新的 M 音符图标，PWA manifest 切换为白色主题
- 响应式布局：桌面左侧栏 + 底部播放条；手机底部导航 + 全屏播放页
- 播放页：桌面歌词固定在封面右侧；手机左右滑动切换封面 / 歌词页
- HTML5 Audio、队列与进度持久化、Media Session、320K/128K 自动降级
- LRC 歌词逐行同步与翻译合并
- 评论：热门 / 最新、楼层回复、评论配图
- 扫码登录
- Docker：`Dockerfile.web.vue` + `prebuilt/vue` + `docker/build-vue.sh`
